# ระบบดาวน์โหลดเกียรติบัตร สาขาวิชาภาษาไทย คณะศึกษาศาสตร์ มหาวิทยาลัยศิลปากร

ระบบค้นหาและดาวน์โหลดเกียรติบัตรออนไลน์สำหรับสาขาวิชาภาษาไทย คณะศึกษาศาสตร์ มหาวิทยาลัยศิลปากร (พระราชวังสนามจันทร์ นครปฐม) เชื่อมต่อฐานข้อมูลจาก Google Sheets พร้อมระบบคุ้มครองข้อมูลส่วนบุคคล ระบบพรีวิวเอกสาร และระบบยื่นคำร้องขอแก้ไขเกียรติบัตรออนไลน์

---

## ผู้พัฒนาระบบ
- **นายณัฐวุฒิ ธนาศิริธนวัชร์**
- นักศึกษาสาขาวิชาภาษาไทย รุ่นที่ ๕๖ คณะศึกษาศาสตร์ มหาวิทยาลัยศิลปากร

---

## ฟีเจอร์สำคัญของระบบ (Key Features)

1. **เชื่อมต่อฐานข้อมูล Google Sheets ผ่าน Sheet ID:**
   - ใช้งานได้ทันทีเพียงวาง Google Sheet ID หรือ URL ของแผ่นงาน
   - ฐานข้อมูลหลัก (ชีต ๑) รองรับ ๔ คอลัมน์:
     1. **ชื่อโครงการ**
     2. **รหัสนักศึกษา**
     3. **ชื่อ-นามสกุล**
     4. **ลิงก์ PDF เกียรติบัตร** (รองรับลิงก์ Google Drive หรือ direct URL)

2. **ระบบรักษาความปลอดภัยและความเป็นส่วนตัว (Privacy-First):**
   - ไม่แสดงรายชื่อผู้เข้าร่วมทั้งหมดบนหน้าเว็บสาธารณะ
   - แสดงผลเฉพาะเกียรติบัตรของบุคคลนั้นเมื่อทำการค้นหาถูกต้อง

3. **การค้นหาที่ยืดหยุ่น:**
   - สามารถเลือกโครงการที่ต้องการดาวน์โหลดได้
   - สลับโหมดการค้นหาได้ระหว่าง **"ค้นหาด้วยรหัสนักศึกษา"** หรือ **"ค้นหาด้วยชื่อ-นามสกุล"** (รองรับการค้นหาด้วยชื่อจริง หรือนามสกุล)

4. **การดูตัวอย่างและดาวน์โหลด:**
   - ปุ่ม **"ดูตัวอย่างเกียรติบัตร"** จะเปิดหน้าต่าง Pop-up แสดงตัวอย่างเอกสาร
   - มีปุ่ม **"ดาวน์โหลดเกียรติบัตร (PDF)"** เด่นชัดอยู่ทั้งในการ์ดและภายใน Pop-up ตัวอย่าง

5. **ระบบยื่นคำร้องขอแก้ไขเกียรติบัตร และแถบติดตามสถานะ:**
   - ผู้ใช้บริการสามารถคลิกปุ่ม **"ยื่นคำร้องขอแก้ไขข้อมูล"**
   - เลือกโครงการ กรอกรหัสนักศึกษา และระบุชื่อที่ถูกต้อง
   - มีปุ่ม **"ตรวจสอบข้อมูล"** ให้ผู้ใช้บริการตรวจสอบความถูกต้องก่อนกดยืนยัน
   - **ออกเลขติดตามอัตโนมัติ** (เช่น `REQ-67-001`) สำหรับใช้ติดตามสถานะ
   - แถบติดตามสถานะ ๔ ขั้นตอน:
     1. *ยื่นคำขอแล้ว*
     2. *แอดมินรับคำขอ*
     3. *กำลังดำเนินการ*
     4. *เสร็จสิ้น แก้ไขแล้ว*

6. **ระบบผู้ดูแลระบบ (Admin Panel):**
   - ปุ่ม Admin อยู่ที่มุมบนขวามือของแถบเมนู
   - ข้อมูลเข้าสู่ระบบ:
     - **Username:** `Kruthai56`
     - **Password:** `kruthai566868`
   - สามารถจัดการข้อมูล (เพิ่ม / ลบ / แก้ไขรายชื่อ) ได้โดยตรงในระบบโดยไม่ต้องแก้ใน Google Sheet
   - มีแถบจัดการคำร้องขอแก้ไขเกียรติบัตร (บันทึกในฐานข้อมูล **ชีต๒**) พร้อมปุ่มอัปเดตสถานะและปุ่มอัปเดตชื่อเข้าสู่ระบบทันที

7. **อัตลักษณ์มหาวิทยาลัยศิลปากร:**
   - โทนสีม่วงสง่างาม ผสมผสานสีทองอร่าม
   - ตราสัญลักษณ์ทางการของมหาวิทยาลัยศิลปากร

## วิธีติดตั้งและรันบนเครื่องคอมพิวเตอร์ (Local Development)

### ความต้องการของระบบ
- **Node.js** เวอร์ชัน 18 ขึ้นไป
- **npm** หรือ **yarn** หรือ **pnpm**

### ขั้นตอนการรัน
```bash
# 1. โคลน Repository
git clone https://github.com/<YOUR_USERNAME>/<YOUR_REPOSITORY>.git

# 2. เข้าสู่โฟลเดอร์ของโปรเจกต์
cd <YOUR_REPOSITORY>

# 3. ติดตั้ง Dependencies
npm install

# 4. รัน Development Server
npm run dev
```

เปิดเว็บเบราว์เซอร์ไปที่ `http://localhost:3000`

### การ Build สำหรับ Production
```bash
npm run build
```
ไฟล์ผลลัพธ์จะถูกสร้างไว้ที่โฟลเดอร์ `dist/`

## วิธีนำขึ้น GitHub และเปิดใช้งาน GitHub Pages

### ๑. นำโค้ดขึ้น GitHub Repository
```bash
# เตรียมไฟล์และคอมมิท
git init
git add .
git commit -m "Initial release of Thai Education Certificate Portal"

# เชื่อมต่อกับ GitHub Repository ของท่าน
git branch -M main
git remote add origin https://github.com/<YOUR_USERNAME>/<YOUR_REPOSITORY>.git
git push -u origin main
```

### ๒. เปิดใช้งาน GitHub Pages ผ่าน GitHub Actions
โปรเจกต์นี้มีไฟล์ Workflow `.github/workflows/deploy.yml` เตรียมไว้ให้อัตโนมัติแล้ว:
1. เข้าไปที่ Repository ของท่านบน GitHub
2. ไปที่เมนู **Settings** > ด้านซ้ายเลือก **Pages**
3. ในหัวข้อ **Build and deployment**:
   - ตรง **Source** ให้เปลี่ยนเป็น **GitHub Actions**
4. ทุกครั้งที่มีการ `git push` ขึ้น Branch `main` ระบบจะทำการ Build และ Deploy เว็บไซต์ให้โดยอัตโนมัติ
5. เว็บไซต์ของท่านจะออนไลน์ที่ `https://<YOUR_USERNAME>.github.io/<YOUR_REPOSITORY>/`

## การ Deploy ไปยัง Vercel หรือ Netlify

### บน Vercel:
1. เข้า [vercel.com](https://vercel.com) แล้วเลือก **Add New Project**
2. เชื่อมต่อกับ GitHub Repository นี้
3. Vercel จะตรวจพบว่าเป็นโปรเจกต์ Vite โดยอัตโนมัติ:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. กด **Deploy** เพื่อเปิดใช้งานทันที
